# 腎臟切片資料收集系統 (Renal Biopsy DB)

收集腎臟切片病人的基本資料、抽血檢查與病理報告的 Windows 單機程式。
欄位依照「Renal biopsy data」投影片設計（13 個區塊），另加上 TSN 腎臟疾病登錄系統的欄位（TSN registry 頁）。

## 功能

| 需求 | 實作方式 |
|---|---|
| 訪客／管理者登入 | 開啟後選擇「訪客登入」（免帳密）或「管理者登入」 |
| 管理者帳密 | `neph88099` / `neph88099`（程式內只存密碼雜湊） |
| 輸入病歷號、身分證字號或姓名查詢 | 號碼須完全相符（身分證大小寫皆可）；姓名可只輸入部分，多位符合時會列出清單讓你選擇 |
| 已有資料可修改 | 列出該病人所有切片紀錄，雙擊即可開啟修改；也可「新增一次切片紀錄」 |
| 沒有資料就新增 | 查無資料時詢問是否建立新病人；程式會自動判斷輸入的是身分證字號、姓名還是病歷號並先帶入 |
| 上傳到程式 | 按「儲存並上傳」寫入資料庫 |
| 管理者匯出 Excel | 依切片年份、性別、年齡、病理診斷、病歷號／身分證字號篩選，並可選擇要匯出的區塊 |
| 管理者匯入 TSN Excel | 匯入 TSN 登錄系統整理出的 Excel 作為基底資料（見下方說明） |

### 資料結構

* **病人層級**（同一位病人共用）：病歷號、身分證字號、姓名、生日、性別、Past history、Operation history
  * 病歷號與身分證字號**至少填一個**，各自不可與其他病人重複；之後隨時可補上另一個號碼
  * 身分證字號會檢查格式與檢查碼（支援新舊式居留證），不符時會提醒但仍可儲存
* **切片層級**（一位病人可有多次切片）：其餘所有欄位
* **TSN registry 頁**：TSN 病患 ID／切片編號／檢驗編號、DM、HTN、發病原因、家族史、危險因子、用藥習慣、Clinical diagnosis、TSN 原始病理診斷文字
* **抽血檢查**：CBC、腎功能／電解質、肝功能／血脂、Immunoglobulin、Endocrine/infection，
  每一組都可輸入多個日期
* **病理診斷**：下拉清單（可複選）＋「其他」自填，匯出時可依此篩選
* **超音波圖片**：可加入圖片檔或直接從剪貼簿貼上
* 年齡（切片時）與 BMI 自動計算
* 日期可輸入 `2024-05-03`、`2024/5/3`、`20240503` 或民國年 `113/05/03`

### Excel 匯出內容

* **Biopsies**：每次切片一列。抽血數值只取「切片日當天」的那一次（當天沒有抽血則留空）。每個診斷另有 0/1 欄位（`Dx: ...`），方便統計
* **Labs_all**：所有日期的抽血紀錄
* **篩選條件**：匯出時間、匯出者與條件

## 匯入 TSN Excel（管理者）

工具列「匯入 TSN Excel」→ 選擇 TSN 登錄系統整理出的 Excel（讀取「全部病患」工作表）。

1. 先顯示**預覽**：會新增幾位病人、幾筆切片，略過哪些列、哪些數值需要核對
2. 按「開始匯入」後，程式會先自動另存一份目前資料（`backups/before_import_…`），可用「從備份還原」復原
3. 同一位病人（相同身分證字號或病歷號）＋相同切片日期視為同一筆紀錄：
   **已有的資料不會被覆蓋，只補上空白欄位**。因此同一個檔案重複匯入也不會產生重複資料，
   之後 TSN 有新資料時可以再匯入一次

對應方式：

* 每一列 = 一次切片；檢驗數值記在**切片日期**（TSN 檢驗表單沒有抽血日期；上傳日期另存在 TSN registry 頁）
* 病理診斷對應到本系統的診斷清單，例如 Membranous glomerulonephritis → Membranous nephropathy、
  Crescentic GN type 1/2/3、Renal transplantation → Transplant kidney biopsy；
  `Others` 與對應不到的診斷放入「其他診斷」，TSN 原始文字保留在 TSN registry 頁
* 會提醒需要核對的數值：Creatinine 大於 BUN（可能欄位對調）、應為數字的欄位不是數字
* 缺身分證字號或切片日期的列會略過並列出

> 資料庫含姓名與身分證字號，請依院內個資規範管理資料夾權限與備份檔。

## 共用網路資料夾使用注意

資料庫是一個 `.db` 檔，可放在醫院共用網路資料夾讓多台電腦使用：

1. 每台電腦第一次開啟時，在登入畫面按「變更資料庫位置…」，選擇共用資料夾中的同一個 `.db` 檔
   （第一台電腦可在該資料夾建立新的資料庫）。
2. **同一筆紀錄同時只能由一台電腦編輯**：其他人開啟時會顯示「正由 XXX 編輯中」，並以唯讀模式開啟。
   若程式異常關閉，鎖定會在 10 分鐘後自動失效。
3. 若兩人同時修改同一病人的基本資料，後存檔的人會收到「資料衝突」提示，資料不會被悄悄覆蓋。
4. 每天第一次開啟時會自動在資料庫旁的 `backups` 資料夾建立備份（保留最近 30 份）。
5. **更新程式版本時，所有電腦要一起換成新版**：新版第一次開啟時會自動升級資料庫格式，升級後舊版程式就無法再開啟這個資料庫。
6. 網路中斷時，存檔會失敗並提示，請恢復連線後再按一次「儲存並上傳」。

> SQLite 放在網路磁碟適合少量使用者（數人）輪流使用；若未來需要大量同時使用，建議改為資料庫伺服器。

## 介面

深藍 + 青色光暈的 AI 風格介面（配色取自科徽），登入畫面有動態神經網路背景；科徽同時用於登入畫面、主畫面標題列與程式圖示。
主題設定在 `renal_biopsy/ui/theme.py`，圖片在 `renal_biopsy/assets/`。

## 備份與還原

| 方式 | 說明 |
|---|---|
| 自動備份 | 每天第一次開啟程式時，自動備份到資料庫旁的 `backups` 資料夾（保留最近 30 份，檔名含日期） |
| 立即備份（管理者） | 工具列「立即備份」→ 選擇存放位置（例如隨身碟、自己的電腦）。完成後會顯示備份中的病人數與紀錄數 |
| 從備份還原（管理者） | 工具列「從備份還原」→ 從清單選擇某一天的備份，或按「選擇其他位置的備份檔…」選隨身碟上的檔案 |

還原時的保護措施：

* 會先檢查檔案是否為本程式的有效備份，並顯示備份內容（病人數、紀錄數、最後修改時間）讓你確認
* 還原前會自動把目前的資料另存為 `backups/before_restore_日期_時間.db`，選錯備份可以再還原回來
* 若有其他電腦正在編輯資料，會提示等對方關閉後再還原
* 還原動作會記錄在資料庫的操作紀錄中

> `backups` 資料夾和資料庫在同一個共用資料夾，能進入資料夾的人可以把兩者一起刪除。
> 請定期用「立即備份」把備份存到共用資料夾以外的地方，並妥善保管（備份檔含病人資料）。

## 安裝與執行

### 使用打包好的 exe（建議）

每次推送程式碼到 GitHub，GitHub Actions 會自動建置 Windows 版：
到 GitHub 專案頁 → **Actions** → 最新一次「Build Windows exe」→ 下載 `RenalBiopsyDB-windows`，
解壓縮後執行 `RenalBiopsyDB.exe`（整個資料夾要一起複製，不需安裝 Python）。

### 從原始碼執行

```bash
pip install -r requirements.txt
python main.py
```

### 測試

```bash
pip install -r requirements.txt -r requirements-dev.txt
python -m pytest tests
```

## 修改欄位

所有欄位都定義在 `renal_biopsy/schema.py`。新增欄位、修改診斷清單或抽血項目，只要改這個檔案，
輸入畫面和 Excel 匯出會自動跟著更新（舊資料不受影響）。

```
  ui/import_dialog.py        匯入 TSN Excel

```
